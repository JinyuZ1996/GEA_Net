# GEA-Net 公式与实现修正

本文档记录代码相对论文稿的必要修正。修正目标是消除维度、符号和训练流程冲突，同时保留“双分支外部注意力 + LightGCN + 少样本适配”的核心设计。

## 1. 原始输入到特征维度

论文令单传感器输入为 `X_i ∈ R^(T×d)`，但两个本地数据集的每个传感器在每个采样点只有一个标量。实现先使用独立共享的轻量一维卷积把 `[T,1]` 映射为 `[T,d]`，再进入外部注意力。卷积在每个传感器上共享参数，不混合传感器节点。

## 2. 外部注意力归一化

论文公式 (3) 对原始打分采用 L2 行归一化。这样会保留负数，不能得到概率意义的注意力，而且模长接近零时不稳定。实现改为：

```text
S = softmax(Q M_K^T / sqrt(d), dim=memory)
A = ColumnNormalize(S)
A = RowNormalize(A)
F_seq = LayerNorm(Q + A M_V)
```

`A` 非负且每个时间步的权重和为 1。`M_K`、`M_V` 仍是整网共享的外部记忆参数。

## 3. 跨传感器注意力权重

论文公式 (6) 使用 `1/(Tα)` 的点积均值。若每行注意力已归一化，该值会随 `T`、`α` 严重缩小，使图分支几乎收不到动态权重。实现使用展平注意力图的余弦相似度：

```text
W_att[i,j] = cosine(vec(A_i), vec(A_j))
```

由于注意力非负，结果位于 `[0,1]`，并显式对称化。

## 4. 图边权不重复门控

论文公式 (2) 已用 `sigmoid(W_e)` 门控先验邻接矩阵，公式 (8) 又乘一次 `sigmoid(W_edge)`，且两者关系未定义。实现合并为每层唯一的可学习结构门：

```text
A_struct[l] = A0 ⊙ sigmoid(sym(W_edge[l]))
A_agg[l] = SymNorm(A_struct[l] + beta * W_att + I)
E[l] = A_agg[l] E[l-1]
```

注意力项允许在先验图之外建立动态连接；`I` 保留自环。

## 5. 稀疏正则

对原始 logits 做 L1 正则会把 logits 推向 0，而 `sigmoid(0)=0.5`，并不会产生稀疏边。实现对先验边上的实际门值 `sigmoid(W_edge)` 做均值 L1 正则。

## 6. β 的含义

论文公式 (8) 把 `β` 定义为结构先验与注意力引导的平衡系数，但实验节又写成“注意力头数 β=4”。全文没有多头注意力公式。实现按公式 (8) 将 `graph_beta` 作为非负融合系数，默认值为 `0.5`；外部注意力采用单组共享记忆。

## 7. MAML 与原型网络的衔接

论文元训练使用带分类层的 MAML，目标适配却直接切换为原型分类，二者的分类头和优化目标不一致。实现采用 Proto-MAML：

1. 支撑集均值特征初始化每类原型；
2. 将欧氏距离分类器等价初始化为线性权重；
3. 在支撑集执行一阶 MAML 内循环；
4. 用查询集损失更新共享编码器；
5. 目标工况评估使用无需梯度更新的原型分类。

这样保留快速初始化学习能力，同时使元训练与目标阶段使用同一距离几何。

## 8. 其他记号

- 论文公式 (1) 的概率定义应使用等号而不是 `∼`。
- 原型分类在代码中使用负平方欧氏距离作为 logits，预测类别与最小欧氏距离完全等价，同时可直接用于交叉熵训练。
- 一致性损失在 L2 归一化后的两分支全局表示上计算，避免单纯特征尺度主导损失。
